# Salva Bolso — Backend

Backend do sistema Salva Bolso, desenvolvido em Python e FastAPI.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker

## Responsabilidades

O backend é responsável por:

- Autenticação de usuários.
- Gerenciamento de contas financeiras.
- Registro de receitas e despesas.
- Importação de transações.
- Conciliação financeira.
- Disponibilização de dados para o aplicativo Flutter.

## Organização

O código principal está localizado em `app/`.

As migrações do banco de dados estão em `alembic/`.
